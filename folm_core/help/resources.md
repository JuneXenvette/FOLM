# What mods need

## xNVSE (New Vegas Script Extender)
Nearly every modern New Vegas mod needs it.

<https://www.nexusmods.com/newvegas/mods/67883>

## FNV 4GB Patcher
Lets New Vegas use 4 GB of memory instead of 2. Needed by almost every setup. FOLM runs the patcher
for you when you install it, and checks before Play that it's still applied.

<https://www.nexusmods.com/newvegas/mods/62552>

## FNV BSA Decompressor
Unpacks the game's compressed archives once, so they load faster and stutter less.

<https://www.nexusmods.com/newvegas/mods/65854>

## FOSE (Fallout Script Extender)
The script extender for Fallout 3.

<https://www.nexusmods.com/fallout3/mods/8606>

## Fallout Anniversary Patcher
Makes the current Steam version of Fallout 3 work with FOSE, and applies the 4 GB fix.

<https://www.nexusmods.com/fallout3/mods/24913>

## FO3 BSA Decompressor
The same archive fix as above, for Fallout 3.

<https://www.nexusmods.com/fallout3/mods/25720>

# Modding tools

## FNVEdit / FO3Edit (xEdit)
Inspect, clean and fix plugins; see and resolve conflicts. Runs from FOLM's Tools tab.

- New Vegas: <https://www.nexusmods.com/newvegas/mods/34703>
- Fallout 3: <https://www.nexusmods.com/fallout3/mods/637>

## xLODGen
Builds distant terrain LOD. Runs from FOLM's Tools tab. Its forum thread has the newest beta.

<https://stepmodifications.org/forum/topic/13451-xlodgen-terrain-lod-beta-for-fnv-fo3-fo4-fo4vr-tes5-sse-tes5vr-enderal/>

## GECK Extender
Fixes and improves the GECK: fewer crashes, faster loading, a better script editor. Almost every mod
maker uses it.

- New Vegas: <https://www.nexusmods.com/newvegas/mods/64888>
- Fallout 3: <https://www.nexusmods.com/fallout3/mods/23425>

## BSArch
Packs and unpacks the games' archives (.bsa), for looking inside them or shipping your own mod.

<https://www.nexusmods.com/newvegas/mods/64745>

## Wrye Flash
Makes a "Bashed Patch" that merges leveled lists, so several mods adding items to the same lists all
work together. A Windows program.

- New Vegas: <https://www.nexusmods.com/newvegas/mods/35003>
- Fallout 3: <https://www.nexusmods.com/fallout3/mods/11336>

## NifSkope
Open and edit the games' 3D models (.nif).

<https://github.com/niftools/nifskope>

## Blender NifTools Addon
Import and export .nif models in Blender. There's also a New Vegas fork:
<https://www.nexusmods.com/newvegas/mods/98797>.

<https://github.com/niftools/blender_niftools_addon>

## GIMP
A free image editor for Linux that opens and saves the games' .dds textures.

<https://www.gimp.org>

## Texconv (DirectXTex)
Microsoft's command-line tool to convert and compress .dds textures.

<https://github.com/microsoft/DirectXTex>
