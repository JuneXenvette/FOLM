# FOLM artwork

`folm-logo.png` and the `folm-icon-*.png` icons are the original FOLM author's own artwork.
They are **not** covered by the GPL-3.0 license that covers FOLM's code.

- FOLM itself and unmodified copies or forks that still call themselves FOLM may use them to show
  what the program is (app icon, README, release pages).
- Don't use them to brand a different project, or for anything sold.

FOLM ships no Bethesda, Obsidian or other third-party logos or artwork, and contributions shouldn't add any.
